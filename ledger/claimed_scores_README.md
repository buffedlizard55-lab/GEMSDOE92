# claimed_scores_20261024.csv

Operator-reported public leaderboard scores for GEMSDOE-site rasters (**CLAIM**, no
organizer receipt exists in this repository).  Reconstructed on 2026-10-24 from the
operator's session prompt as carried in session memory; the verbatim prompt text was
**not** retained in the repo by earlier sessions (`ledger/raw_paste.txt` holds only the
5-row climb chain).  `match_confidence` says how the raster was tied to the claim:

* `exact` / `high` - file name and dot count agree with the claim text,
* `medium` - the claim was site-level; the file was chosen by name and may be one of
  several rasters in that site,
* `low` / `unmatched` - no reliable raster; kept for completeness, never used as a voter.
