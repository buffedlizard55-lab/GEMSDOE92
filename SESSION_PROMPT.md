# Session start pointer

**Read [`README.md`](README.md) first at the start of every session.** It contains the complete, canonical operating prompt, current evidence labels, blocking registry result, experiment limits, data-access cautions, and current artifact status.

This file is intentionally not a second source of operating rules. Earlier session addenda and results elsewhere in the repository are historical records; they may describe superseded candidates, old data availability, or previous site snapshots. Follow the README and [`docs/REVIEW_CURRENT.md`](docs/REVIEW_CURRENT.md) for current status. Never treat a historical score, holdout, or registry measurement as a fresh result unless its provenance says it was rerun.
