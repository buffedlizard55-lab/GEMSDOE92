## Required gate sequence before any future experiment

1. Resolve the dense-witness policy without silently exempting the witness or changing the 70% rule.
2. Obtain the pinned feature stack through an authorized source, validate its hash/grid/provenance, and check reuse terms. A GitHub owner mirror only establishes byte identity with that mirror.
3. Select one method lane and pre-register one surface. Check surface uniqueness before placement; if it fails, log a duplicate and stop.
4. For any lane still eligible, run every feature alone through the shared buffered whole-segment holdout as a leakage canary. AUC above 0.90 is leakage until explained.
5. Use the shared evaluator and writer; compare paired HOLDOUT-DTI against the current comparable holdout best and report evaluator, withheld-positive count, and 95% CI. Holdout is not an organizer score.
6. Check final-dot registry uniqueness and all local format gates. The separate selector, not this review, decides whether any real weekly slot is spent.
