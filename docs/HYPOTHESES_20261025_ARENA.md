# Conditional, untested geological hypotheses — 2026-10-25 repository review

## Scope and decision

This is a fresh ranking of methods not implemented in the tracked `gems/` or `scripts/` code inspected for this review. Similar ideas are already mentioned in older research notes; this is **not** a claim of worldwide or literature novelty. Expected value is a qualitative research-priority ranking only. No numerical HOLDOUT-DTI gain is projected.

**No candidate was built or scored.** The pre-placement rejection proof establishes that the pinned public witness is positive in every valid footprint cell. Under the requested literal rule, any nonempty in-footprint dot set would have `REGISTRY-MEASUREMENT` forward overlap `1.0`, above `0.70`; the run must stop before placement. Independently, the 19-band feature stack is absent from this checkout and its only pinned source is an owner-mirror GitHub copy with upstream provenance and reuse rights flagged as unverified. Therefore the rank-1 candidate was **not validated on HOLDOUT-DTI**, no canary was run, and no submission slot was touched.
