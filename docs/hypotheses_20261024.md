## Validation decision and stopping condition

No new experiment was run in this review. The top *untried* hypothesis is multi-scale geophysical edge persistence, but it cannot be validated now because `training_features.tif` is absent from `.cache/gems_inputs/` and its official competition download requires account access. Do not claim a holdout result, do not substitute owner-mirror data with unchecked redistribution terms, and do not touch a weekly submission slot. When authorized data is staged, run the shared cached feature stack and `vendor/gems57/evaluate_holdout.py` / shared writer; test each feature alone (AUC >0.90 is leakage until proven otherwise), withhold whole fault segments and buffers, derive catalogue features from visible segments only, mask visible faults pixel-exactly, and report pooled DTI α=0.2, β=0.8, 300 m triangular kernel with withheld count and 95% CI. Stop if either pre-placement surface or final-dot comparison breaches the configured lane thresholds.
