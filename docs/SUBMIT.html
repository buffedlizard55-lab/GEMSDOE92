How the portal error was fixed (so you don’t have to debug it)

The portal checks every pixel — including outside the study area. Past failures put −3.4028235e+38 (the training stack’s nodata sentinel) or a stray NaN inside the footprint, which is outside [0,1]. This file avoids both by writing nodata=None and outside=0.0 (finite), then asserting n_violations=0 min=0.0 max=1.0 nan_pixels=0 on reread. Both twins pass.
