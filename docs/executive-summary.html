4. What this submission is (method)

  • Hypothesis: blind geothermal strands localize at visible-tract step-overs / relay ramps (3–10 px off mapped traces, strike continuation of trace tips), under-mapped in the USGS/INGENIOUS catalogue.
  • Mechanism: 5,000 unit-mass dots placed by visible-geometry favourability (strike alignment × distance decay from trace tips), 1 px minimum spacing, all dots > 3 px from the catalogue (zero catalogue mass), EPSG:32611 100 m grid.
  • Non-fault mimic named: erosional notches, alluvial-fan heads and pluvial-lake shoreline terminations can create tip-like trace ends without displacement.
  • How it differs from prior lanes in this repo: STEPOVER places new dots off-catalogue at trace tips; MASS/PRUNE/CONCENTRATION/RELIEF reallocate on H19-5 support or relief/block priors; SNAP moves existing dots <= 2 px onto edge response.
