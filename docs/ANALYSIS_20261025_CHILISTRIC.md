### 1.2 Exact Mathematical Mechanics of the DrivenData Distance-Weighted Tversky Index (`DTI`)

We verified the competition metric directly from the official DrivenData reference repository (`drivendataorg/gems-prize-reference-solution`, `unet-mc-cv-reference-solution.ipynb`, Cell 16, authored with Prof. John Lipor) and its exact implementation in `vendor/gems57/metric.py:dti_exact`.

Let $\Omega \subset \{0,\dots,3729\} \times \{0,\dots,3291\}$ be the valid Great Basin study footprint ($|\Omega| = 5,167,373$ pixels at $\Delta x = 100\text{ m}$ in $\text{EPSG:32611}$, out of $3730 \times 3292 = 12,279,160$ grid cells), let $C \subset \Omega$ be the public USGS/INGENIOUS Quaternary fault catalogue (`labels.tif == existing_faults.tif`, SHA-256 `7ba308ccdc44...`, $|C| = 60,988$ pixels $= 1.180\%$ of $\Omega$), and let $G \subset \Omega \setminus C$ be the withheld hidden fault pixels. Define the $300\text{ m}$ ($R = 3.0\text{ px}$) linear-decay tent kernel
$$K(d) = \max\!\left(0,\; 1 - \frac{d}{R}\right), \qquad R = 3.0\text{ px},$$
and for any field $u : \Omega \to [0, 1]$ define its morphological tent dilation $(D_K u)(x) = \max_{z \in \Omega:\,\|x - z\|_2 < R} u(z)\,K(\|x - z\|_2)$. Writing $\tilde{y}(x) = (D_K \mathbf{1}_G)(x) = \max_{g \in G} K(\|x - g\|_2)$ for the buffered hidden truth and $\tilde{p}(x) = (D_K \hat{y})(x)$ for the buffered prediction on the evaluated domain $E = \Omega \setminus M_{\text{known}}$, `vendor/gems57/metric.py` evaluates (`alpha = 0.2`, `beta = 0.8`):
$$\mathrm{TP} = \sum_{x \in E} \tilde{p}(x)\,\tilde{y}(x), \qquad \mathrm{FP} = \sum_{x \in E} \tilde{p}(x)\bigl(1 - \tilde{y}(x)\bigr), \qquad \mathrm{FN} = \sum_{x \in E} \bigl(1 - \tilde{p}(x)\bigr)\tilde{y}(x),$$
$$\mathrm{DTI}(\hat{y}, G) = \frac{\mathrm{TP}}{\mathrm{TP} + 0.2\,\mathrm{FP} + 0.8\,\mathrm{FN}} = \frac{\mathrm{TP}}{0.8\,Y + 0.2\,\mathrm{TP} + 0.2\,\mathrm{FP}}, \qquad Y = \sum_{x \in E} \tilde{y}(x).$$
