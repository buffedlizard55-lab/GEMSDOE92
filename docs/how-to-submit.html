How to submit after a candidate is explicitly cleared

  1. Download the exact cleared single-band GeoTIFF, or a ZIP containing exactly one GeoTIFF. Do not re-save or alter it.
  2. Open the official DrivenData submission page. Check the current weekly limit shown there, then select the cleared file.
  3. Enter the separately approved unique submission name and a note of at most 140 characters. Submit only after the separate selector authorizes it, then record the organizer's receipt and score.

The raster must match the competition template's CRS, shape, and geotransform. To diagnose “Predicted values must be in range [0, 1]”, validate stored pixel values (including exterior pixels and nodata sentinels), require finite values within [0,1], and use the shared writer/validator against the exact template.
