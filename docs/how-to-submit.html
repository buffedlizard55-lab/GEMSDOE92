How to submit after clearance

DO NOT SUBMIT NOW

No eligible file is available. Format validation alone does not grant clearance. The weekly submission selector is a separate step; consult the current portal limit.

  1. Once all required checks pass, download the newly cleared GeoTIFF from the executive summary.
  2. At the official submission portal, choose the single-band GeoTIFF (or ZIP containing only that GeoTIFF).
  3. Enter its supplied short note, submit within the portal's current cap, and preserve the organizer receipt.

For “Predicted values must be in range [0, 1]”, validate every stored pixel, including outside the footprint, for finite values in that range; compare CRS, shape and transform to the official sample. Do not clip a file and presume it is cleared.
