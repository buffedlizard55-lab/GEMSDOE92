Fixing “Predicted values must be in range [0, 1]”

This error comes from cells the validator reads as outside [0, 1]. The usual causes are a nodata sentinel such as −3.4028e38 stored outside the study area, NaN/inf values, values above 1 (e.g. 0–255 or 0–100 scaling), or negative values. All files served here are all-finite with values in [0, 1]. To repair any other raster:

import numpy as np, rasterio
with rasterio.open("in.tif") as s:
    a = s.read(1).astype("float32"); prof = s.profile
a = np.nan_to_num(a, nan=0.0, posinf=1.0, neginf=0.0)
a[a < -1e30] = 0.0                      # nodata sentinels
a = np.clip(a, 0.0, 1.0).astype("float32")
prof.update(dtype="float32", count=1, nodata=None, compress="deflate")
with rasterio.open("out.tif", "w", **prof) as d:
    d.write(a, 1)
