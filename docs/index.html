What was generated?

STEPOVER places 5,000 unit-mass dots in visible-fault step-over / relay-ramp zones: 3–10 px off the mapped catalogue, aligned with the strike continuation of visible trace tips. It is not a copy of the GEMSDOE32 parent or any prior GEMSDOE92 release.

The named non-fault mimic is an erosional notch, alluvial-fan head, or pluvial-lake shoreline termination that can create a tip-like trace end without fault displacement.

Detailed reasoning, including why the 0.2778 GEMSDOE32 number is a CLAIM rather than an organizer-confirmed receipt and why beating it cannot be proven locally, is in docs/ANALYSIS.md. The machine-readable run card is evidence/run_card.json.
