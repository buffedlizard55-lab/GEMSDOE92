1. Paired-profile throw persistence — highest qualitative priority, moderate cost

Layers / signature
Band 12 det_elev + Band 19 det_elev_slope; estimate signed step offsets across multiple cross-strike profiles, requiring consistent polarity and trace persistence across scales.
Catalogue-missing rationale
A subtle scarp may retain a coherent DEM offset while producing little magnetic or gravity contrast and being absent from prior mapping.
Difference from this repo
BREAKLINE uses unsigned slope-break magnitude × orientation coherence; SCARPPOL uses local signed fall-line curvature. This candidate tests repeated cross-profile step amplitude and polarity.
Named mimic
Lake Lahontan shoreline risers, alluvial-fan margins, channel banks, lithologic contacts.
Cost / status
Moderate computation and screening; likely no new data once the pinned stack is available. Stack cache is absent, so this is not viable for validation now.

2. Cross-field gravity–magnetic edge termination/offset — moderate, uncertain benefit; medium/high cost

Layers / signature
Recorded GeoDAWN magnetic products (Bands 3/9/14) and gravity products (Bands 5/18); associate orientation-coherent edges and score systematic termination or offset rather than simple co-location.
Catalogue-missing rationale
Buried basement faults may offset or terminate contrasts beneath basin fill without a visible scarp.
Difference from this repo
ANASIG uses magnetic analytic signal alone. The GRAVCrest gravity-only screen was not promoted. This tests a joint cross-field relationship not implemented here.
Named mimic
Intrusive contacts, volcanic-flow boundaries, ordinary lithologic juxtaposition.
Cost / status
Medium/high: derivatives, line orientation, and cross-field association controls. The feature stack is not cached; not viable for validation now.

3. Signed dilatation at off-skeleton relay gaps — lower/moderate, uncertain benefit; medium cost

Layers / signature
Band 8 geod_dilaterate, Band 7 geod_shearrate, and DEM lineament geometry from Bands 12/19; test localized positive dilatation/gradient at the gap between independently detected non-collinear tips.
Catalogue-missing rationale
An actively opening relay or pull-apart could maintain permeability while its connecting splay remains unmapped or geomorphically subtle.
Difference from this repo
DILATATION re-ranked skeleton-supported dots by one strain field; STRAINBREAK multiplied Band-4 invariant by DEM break strength. This tests signed Band-8 dilation at off-skeleton relay geometry.
Named mimic
Interseismic elastic strain around locked faults, basin compaction, pumping-related subsidence.
Cost / status
Medium: requires independent tip/relay geometry. The feature stack is not cached; not viable for validation now.

4. Drainage-crossing persistence — uncertain potential, highest cost; external data gate

Layers / signature
DEM Bands 12/19 plus USGS hydrography; retain linear offsets that cross channels consistently and suppress breaks parallel to channels or confined to one bank.
Catalogue-missing rationale
A tectonic scarp can offset drainage where a fault is not represented in the existing catalogue.
Difference from this repo
BREAKLINE is an unconditioned terrain score; this explicitly tests drainage as a false-positive control.
Named mimic
Erosional knickpoints, road embankments, terrace risers.
Cost / status
High: external hydrography acquisition, grid alignment, and coverage QA. USGS 3D Hydrography Program / National Map downloader are source leads, but access, coverage, and license were not checked here. Not viable now.
