Answer to the question asked

  1. Best supplied submission among the nine focus sites: GEMSDOE32 h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros at 0.2778 CLAIM. It is not unique (byte-identical copies in 17 other repositories), so downloading and re-submitting it would be a duplicate of an already-scored raster.
  2. Why that family scores well is geometric and metric-legal, not geological luck: binary dots on a 2.8 px lattice match the 300 m triangular kernel, so successive dots stop duplicating the same truth cell, while the >2 px catalogue collar removes mass the organizers mask out. Under DTI = TPw/(TPw + 0.2 FPw + 0.8 FNw) the TP term takes a maximum over dots while FP sums linearly, so 121,131 skeleton px (0.1922 CLAIM) earn less than 37,654 spaced dots (0.2778 CLAIM) even though they cover more line.
  3. Can we beat it? Only by finding truth the catalogue does not contain - i.e. a better detector, not a re-allocation. The MODEL sensitivity table below shows the exact break-even: an added dot is worth its marginal truth credit against a bar of alpha x DTI ~ 0.056, so a new dot set needs roughly a 10% hit rate just to match the parent and ~20% to beat it by +0.05. This session's new mechanism (H-92M) did not demonstrate that, and the honest result is reported as negative.
  4. What is actually downloadable and submittable right now: the H-92M raster below - format-validated and 100% unique by bytes (no other repo serves this SHA-256), with its scientific-gate failures stated next to it rather than hidden.

How to submit (exactly)

  1. Download the -zeros raster (all cells finite, in [0,1], zeros outside the footprint). The -nan research variant is not uploadable: NaN outside the footprint is rejected with "Predicted values must be in range [0, 1]".
  2. On the DrivenData submission page choose File to submit - the .tif, or the .zip containing exactly that one GeoTIFF.
  3. Paste the note from the receipt JSON (≤140 chars) so the run is identifiable later, e.g. H-92M MDC additive expansion: parent lineage fully retained, +22000 new dots from non-local morpho-disequilibrium (front sinuosity, relie
  4. The portal validates CRS/shape/geotransform against sample_submission.tif; local validation already ran 11 gates (all listed in evidence/mdc_run_card_20261031.json).
