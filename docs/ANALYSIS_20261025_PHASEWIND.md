## Hypothesis and experiment

The ranked pre-analysis plan is [`HYPOTHESES_20261025_PHASEWIND.md`](HYPOTHESES_20261025_PHASEWIND.md). `PHASEWIND` was the selected lane: scale-persistent winding of the complex derivative-of-Gaussian phase of Band 2 RTP at 2/4/8 pixels (200/400/800 m), intended to flag terminations or offsets of magnetized basement contacts that might correspond to buried fault splays. Named non-fault mimics include dike/intrusion tips, volcanic-flow boundaries, remanent magnetization, gridding seams, and low-amplitude noise. The operator consumes the RTP grid, not catalogue distances or labels. Implementation note: the code does not explicitly multiply each gradient by σ; that positive scalar would leave phase winding unchanged, and the amplitude is converted to a within-scale percentile rank with a scale-relative floor, so the feature is invariant to the omitted factor.

The original common budget was 37,654 dots with the shared 2.83-pixel spacing floor. The shared emitter could not realize that budget for any proposed arm without zero-score filler or weakening the spacing rule. Before DTI, the primary was fixed at 20,000 dots (below its measured capacity on both seeds), and only that primary was scored; the two ablations were not scored. This amendment is recorded in the hypothesis plan and means its DTI should not be called a like-for-like comparison with the 37,654-dot reference.

The feature stack was restored from the pinned owner-repository mirror and all 12 input hashes/byte lengths verified. Band 2 of `.cache/gems_inputs/training_features.tif` was used. The shared buffered-component holdout used seeds 20 and 30, four spatial quadrants per seed, whole 8-connected catalogue components with buffers, fold-visible `d_visible > 2 px` emission, and the shared evaluator's exact visible-fault mask.
