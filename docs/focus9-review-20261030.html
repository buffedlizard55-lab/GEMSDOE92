Untried in this repository’s integrated implementation (not novel ideas)

These hypotheses were previously documented in docs/HYPOTHESES_20261028_9649DFC1.md. No corresponding integrated implementation or experiment receipt was found in the inspected gems/ modules. They are untested implementation candidates, not newly invented hypotheses. Because the assigned method paragraph is missing, none is selected as the current method lane and none was run.

  1. NWIS hydraulic-head / seasonal phase-lag barrier. Compare pumping- and screen-depth-controlled groundwater-level response across nearby wells on opposite sides of a candidate concealed structure; seek a persistent cross-strike head or seasonal-lag discontinuity. Main confounders: pumping, irrigation, aquifer boundaries, sparse well coverage. USGS Water Services.
  2. ASTER TIR + Landsat SWIR alteration seam. Test co-registered silica/clay alteration boundaries against lithology and land-cover controls; require continuity aligned with structural corridors rather than broad felsic or playa units. Main confounders: lithologic contacts, dunes, mine waste, sensor-registration error. NASA LP DAAC ASTER GED v3 · USGS Landsat Collection 2.
  3. Event-specific ComCat focal-mechanism consensus × geodetic strain. Use mechanism-plane uncertainty and event quality to test whether local nodal planes align with geodetic strain and mapped independent lineaments; separate induced sequences and aftershocks. Main confounders: sparse focal mechanisms, multiple nodal planes, induced seismicity, and strong spatial sampling bias. USGS FDSN event service · ComCat documentation.
  4. Repeat-pass thermal persistence. Test whether seasonally normalized, multi-date land-surface-temperature residual lineaments persist along structures after elevation, aspect, land-cover, irrigation, and cloud-quality controls. Main confounders: transient surface flux, vegetation/soil moisture, emissivity and revisit gaps. Landsat Collection 2.

No expected numerical gain is asserted. These candidates are ranked only by directness to structures, data/coverage burden, and confounder risk; live data availability and terms were not checked.
